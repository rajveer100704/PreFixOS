# Security Policy

## Supported Versions

The following versions of PrefixOS are currently supported with security updates:

| Version | Supported |
| :--- | :--- |
| `v1.0.x` | ✅ Supported |
| `< 1.0.0` | ❌ Unsupported |

## Reporting a Vulnerability

Please report security vulnerabilities by emailing `security@prefixos.io`. We aim to acknowledge reports within 24 hours and issue security patches within 7 business days.
